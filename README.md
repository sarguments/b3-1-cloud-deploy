# B3-1 내가 만든 웹사이트를 인터넷에 올려 누구나 쓰게 하기

코딧세이 AI 올인원 본과정 B3-1 미션 저장소입니다.

## 범위
AWS VPC·Subnet·IGW·EC2·Nginx·보안그룹 최소권한·트러블슈팅 보고서·리소스 정리

## 개발 환경
AWS 서울 리전(ap-northeast-2)에서 진행하는 배포 실습입니다. 실행할 웹사이트와 클라우드 자원은 실습 착수 시 준비합니다.
인증정보와 개인 키는 저장소에 올리지 않습니다.

### 새 환경에서 준비

Git을 설치한 뒤 새 기기에서 저장소를 받습니다.

```bash
git clone https://github.com/sarguments/b3-1-cloud-deploy.git
cd b3-1-cloud-deploy
```

Git과 SSH를 확인합니다.

```bash
git --version
ssh -V
```

AWS 계정·리전·비용 조건을 실습 시작 시 확인합니다. AWS CLI는 필수가 아니며, 네트워크와 서버 설정은 미션 수행 단계에서 만듭니다.

## 준비 상태
Git과 SSH 명령을 확인했습니다. AWS 자원은 아직 만들지 않았습니다. 이 저장소에는 배포 구성이나 실행 증거를 아직 기록하지 않았습니다.
네트워크·서버·보안 설정과 리소스 정리 과정은 작성자가 직접 수행하고 기록합니다.
